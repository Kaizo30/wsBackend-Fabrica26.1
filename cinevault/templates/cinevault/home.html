bem-vindo ao cinevault

um sistema web para gerenciar seu catálogo de filmes. cadastre filmes e categorias, organize seu acervo e utilize a integração com a OMDb API para buscar informações de filmes externos.

gerenciar categorias gerenciar filmes buscar filme na api

sobre o sistema

o cinevault foi desenvolvido com django para demonstrar:

  • crud completo de categorias
  • crud completo de filmes
  • relacionamento entre entidades
  • uso de django templates
  • consumo de api externa (OMDb API)
  • painel administrativo do django

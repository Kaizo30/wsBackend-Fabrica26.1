# wsBackend-Fabrica26.1

## descrição
projeto django de catálogo de filmes com categorias, CRUD completo e consumo de API externa (OMDb API).

## funcionalidades
- CRUD de categorias
- CRUD de filmes
- relacionamento entre entidades
- painel admin do django
- consumo de API externa para buscar dados de filmes
- interface com Django Template

## tecnologias
- Python
- Django
- HTML
- CSS
- Requests

## como executar
1. clonar o repositório
2. criar e ativar a venv
3. instalar dependências:
   pip install -r requirements.txt
4. rodar migrações:
   python manage.py migrate
5. executar:
   python manage.py runserver
